# Architecture & Harmonization Design Notes

This repository implements the [Harmonization of MODIS and VIIRS Hot Spots](./README.md) solution as a decoupled static SPA and containerized API.

## System Split

### 1. Frontend (`ui/` — Pure React + TypeScript + Vite on GitHub Pages)

- **Public Availability**: Publicly accessible on GitHub Pages at [https://avbelkin.github.io/nasa-space-apps-sg](https://avbelkin.github.io/nasa-space-apps-sg), deployed via [deploy-ui.yml](../.github/workflows/deploy-ui.yml).
- **Earth-First Mapping Engine (`maplibre-gl`)**: Keyless **MapLibre GL JS** canvas defaulting to a **3D `globe` projection** (with an optional 2D `mercator` toggle) over **EOX Sentinel-2 Cloudless (`s2cloudless-2025_3857`)** raster WMTS imagery (`{z}/{y}/{x}.jpg` with required EOX/Copernicus attribution) to visualize active-fire hotspots, typical seasonal activity bands, and current calendar anomaly departures directly on Earth.
- **Two-Tier CSS Grid Layout**:
  - **Outer Controls Wrapper (`.app-frame`)**: CSS Grid page shell wrapping perimeter controls *around* the map (stacked below 60rem):
    - `topbar` (`<header>`) — **Earth Fire Calendar** title (provisional title; no NASA branding or logos), a one-line plain-language subtitle, and an always-visible **Sample index** badge (the regional index and month strip are illustrative; fire spots are live); two lines (≤ 72 px) on a 375 px phone.
    - `timeline` (`<section>`) — Month strip: worldwide fire activity per month in a fixed 12-column grid (6 × 2 when narrow), each month a gray "typical" band and a "this year" bar on one 0–100 scale, ▲/▼ above months that depart from typical, the selected month's value, a current-month dot, and hover/focus tooltips (Escape hides them). Empty slots are reserved for a year axis, period selector and CSV export.
    - `sidepanel` (`<aside>`) — Area/Period readout (✕ or Escape clears a selected location), Harmonized | MODIS | VIIRS sensor segment, summary (the month worldwide or the selected location: status, typical vs. this year, delta, peak months, sensor agreement, note), locations (Singapore pinned first, remaining locations sorted by size of departure), live 24h NASA FIRMS hotspot metrics (spot count, peak FRP, MODIS/VIIRS counts, latest detection), collapsed `<details>` for Satellites and Diagnostics (API status, Check API, TLE source), and a `<footer>` with one credit line (`NASA FIRMS` live spots with the sample regional index flagged, `CelesTrak`, Extremum clouds, NASA GIBS rain & night lights, `EOX/Copernicus` Sentinel-2, NASA non-affiliation), collapsible "Sources and credits" and a small data-service indicator.
    - `legend` (`<section>`) — The map legend as a compact row (one inline flow, one or two lines on a laptop) below `timeline` and `sidepanel` (last on a phone), outside the map stage: while live NASA FIRMS spots are loaded, one saturated-red active-fire spot key (size reflects FRP), otherwise the sample status marks drawn exactly as on the map (`StatusMark`); nadir/wide swath swatches and MODIS/VIIRS track swatches from `dataPalette.ts` while orbits are shown, rain dot intensity key (currently experimental bright-blue `#4d96ff` solid dot key, or the 6-stop rainbow calibration / white modes, plus lookback/effective UTC timestamp) while rain clouds are enabled above `z6`, "Your location" once located, and the current coordinates/zoom.
  - **Inner Map CSS Grid Container (`.map-stage`)**: The full-bleed MapLibre canvas spans all tracks under two HUD areas: `hud-top-end` holds a column of icon buttons (zoom, My Location with its error message beside it, reset view), a `2D | 3D` segment, the orbits, clouds, rain clouds (`z6+`), night-time lights and live fire spots toggles and, while spots pulse, a pause-pulse toggle (folded into two columns on maps narrower than 36rem or shorter than 34rem, and four columns below 26rem), paired with the top-end rain time lookback pill (`-30m` / `+30m` steppers + preset selector when rain clouds are visible above `z6` or a lookback offset is active); `hud-bottom-end` (the map column, beside the control column so the two never stack on a short map) holds one bottom row with the hover/pinned fire spot card at its start and the satellite overpass freshness card while orbits are shown (a foldable card: open by default on maps at least 48rem wide, folded to its "Satellite passes" header on narrower maps so it does not hide marks at the default view), kept just above MapLibre's compact `attributionControl` (EOX/Copernicus basemap, `NASA FIRMS` active fires with the sample regional index flagged, `CelesTrak`, Extremum clouds, NASA GIBS GPM IMERG precipitation & night lights) by tracking the control's height, so no HUD element overlaps the attribution in its collapsed or expanded state.
- **Sensor Transparency & Accessible Visuals**: The Harmonized / MODIS / VIIRS segment (ARIA radio group, arrow keys) filters the map, the panel and the satellite card. Status is shape plus color, on the map and in the legend from one definition (`statusMarks.ts`): ▲ above typical (orange), hollow ○ typical, ▼ below typical (dark blue, ≥ 3:1 lightness contrast to orange); one ±8-point classifier sets the status of locations and months. Data colors live in `dataPalette.ts`, one hue per meaning (MODIS satellites green, VIIRS magenta/violet); the team's fixed swath hues (pale blue nadir, pale orange wide) are kept there too and drawn at low opacity. Locations are selected from the list or by clicking a map mark; while live NASA FIRMS spots are loaded the sample marks (and their selection ring) are hidden and the list is the way to select. Active fire spots use a single high-saturation true red (`#ff1a00`, zero blue channel so blurred pulses never drift into pink/magenta and stay distinct from amber/gold VIIRS night-time lights) in `dataPalette.ts`, while FRP continues to drive spot size. Focus styles, coarse-pointer touch targets, light/dark themes and `forced-colors` support are kept.
- **URL Hash, LocalStorage & Geolocation State**: Viewport (`z`, `lat`, `lng`) and controls (`sensor`, `proj`, `month`, `orbits`, `clouds`, `rain` (only `rain=0` when off), `rainBack` (30-min snapped lookback up to `720`, omitted at `0`), `lights` (only `lights=0` when off), `fires` (only `fires=0` when off), `region`, plus extensible feature parameters; one codec registry in `urlHashState.ts`) sync continuously into `window.location.hash`, and the same state without `month` into `window.localStorage` (`nasa_fire_calendar_state_v2`; the older `nasa_fire_calendar_url_hash` key, auto-written by earlier builds, is ignored). A URL hash wins; otherwise viewport, sensor, projection, orbits, clouds, rain, rainBack, lights, fires and region restore from storage. The month comes only from the hash, else it is the current month. Orbits, clouds, rain clouds, night-time lights and fire spots are on by default. The default viewport opens on Singapore (`1.3521° N, 103.8198° E`) at 3D globe zoom `z3`. On a first visit (no URL hash or saved `localStorage` state), browser geolocation runs once in the background: it marks the visitor's position and only rotates the globe (keeping `z3`) when the located coordinates are at least `100 km` from Singapore, preventing camera bounce for nearby visitors; the HUD **My Location** button explicitly jumps and zooms to the user's coarse browser position, capped at default max zoom `z7`.
- **Day/Night Terminator Satellite Clouds Layer (`satelliteCloudLayer.ts`)**: Renders live `258×258` (`256px` + `1px` gutter) `VIS/IR` cloud PNG tiles (`R = 10.8 µm IR`, `G = solar VIS`) via a MapLibre GL JS WebGL2 `CustomLayerInterface` supporting both `globe` and `mercator` projections, NW cloud-top embossing, day/night terminator color blending, zoom fade (`z5.25` → `z9`), and 5-minute visibility-aware refresh, stacked above the basemap and underneath all satellite orbits, swaths, and hotspots. Toggled from the map control column (`clouds` hash key).
- **Smooth Global Rain Clouds Layer (`rainCloudLayer.ts`, `rainCloudShader.ts`)**: Renders keyless `256×256` NASA GIBS WMTS `IMERG_Precipitation_Rate_30min` (GPM half-hourly) precipitation tiles fetched exclusively at `z3` (covering tiles below `z3` subdivided into `z3` quads to prevent 3D globe horizon gaps), indexed through the embedded GPM palette into `304×304` wide-gutter (`24px`) `gl.RG16F` half-float textures pre-filtered with 3 separable Gaussian passes and smoothly sampled in WebGL2 with a 9-point isotropic Cubic B-Spline filter. Projects a map-anchored, zoom-octave nested (`L_0 ⊂ L_1`) staggered hex dot pattern whose opacity scales `0 → 1` from the experimental `0.30` cutoff (`RAIN_DOT_INTENSITY_CUTOFF`) to strong rain cores (`0.72+`) in bright blue (`#4d96ff` in experimental `solid` mode, with `rainbow` and `white` modes kept switchable) composited over an easily removable neutral overcast cloud backdrop (`ENABLE_RAIN_CLOUD_BACKDROP` / `setCloudBackdropEnabled`). Blends in linearly across `z6` → `z9` as VIS/IR clouds fade out, holds full opacity `z9` → `z11`, fades out `z11` → `z14.5`, supports 30-minute lookback stepping (`Latest`, `-1h`, `-2h`, `-4h`, `-6h`, `-12h`, resolved against GIBS `WMTSCapabilities.xml` `Domains`), and is stacked directly below `satellite-swaths-wide-fill`. Toggled from the map control column (`rain` / `rainBack` hash keys).
- **Night-Hemisphere VIIRS Black Marble Layer (`nightLightsLayer.ts`)**: Renders keyless `256×256` NASA GIBS Gap-Filled BRDF-Corrected Day/Night Band tiles (`VIIRS_NOAA20_GapFilled_BRDF_Corrected_DayNightBand_Radiance`) via a MapLibre GL JS WebGL2 `CustomLayerInterface` masked in real time to Earth's nighttime side of the solar terminator across `z0–z4`, smoothly cross-fading across `z4` → `z6` into EOX Sentinel-2 Cloudless directly underneath `satelliteCloudLayer.ts`. Toggled from the map control column (`lights` hash key, `lights=0` when off).
- **Live Animated Active-Fire Spots (`fireSpots.ts`, `fireSpotsAnimation.ts`, `fireTimeline.ts`, `satelliteOverpassTimeline.ts`, `FireDetectionsTimelineCard.tsx`)**: Streams compact 24h NASA FIRMS detections (`MODIS_NRT` + `VIIRS_NOAA20_NRT` + `VIIRS_NOAA21_NRT`) every 15 minutes from `/api/fires/spots`, applying hierarchical `z1`–`z7` spatial decluttering above `z1` and rendering a crisp core circle layer scaled by FRP (`1–250 MW -> 0.5–1.5x`) and shaded by confidence (`25–100% -> 0.6–1.0`) above 4 spatial phase-cohort pulse layers (`80ms` tick modulated by 24h linear activity decay `[1 -> 0]` and `sin(2π * cycles + phase)` frequency sweep). Automatically pauses pulsing after 5 minutes of user inactivity, on hidden tabs, when scrolled out of the viewport, or when `prefers-reduced-motion: reduce` is enabled while preserving static spot legibility, and supports declutter-aware 8 px hover/click tooltips expanding hidden `z1`–`z6` neighbors merged into a visible leader spot (shown in the bottom row of the map; Escape unpins a pinned card before it clears a selected region). All fire spot cards (`1+` detections) show a 24h (`24 × 1h`) timeline plotted on the browser's local clock with a place-relative solar altitude/horizon curve over a horizon-split background (`#1e293b` above horizon, `#000000` below horizon), confidence-opacity satellite-colored FRP bars (`>= 1rem` slot columns using the shared Terra/Aqua/NOAA-20/NOAA-21 palette matching the legend and orbital tracks, grouping multiple same-hour spacecraft as equal-width side-by-side sub-bars under `<winner> +N` rotated labels), client-side J2 orbital **fire negatives** (propagated over `-26h..+30m` from server-supplied live CelesTrak TLE lines with a `0.05°` spatial cell cache and `±25m` cross-slot positive-pass suppression, rendered on diagonal-striped grey columns), a right-side NRT **processing-time cutoff** zone (`90m` VIIRS / `120m` MODIS) with muted pending-pass indicators, and a visually hidden semantic data table. Toggled from the map control column (`fires` hash key, `fires=0` when off).
- **Live MODIS & VIIRS Orbital & Swath Overlay**: Renders a two-part `-180m` past ground-track tail per satellite (solid ready tail older than each satellite's NRT processing lag — `90m` VIIRS / `120m` MODIS — and dashed `4,2` in-processing tail within the lag window up to the live spacecraft position, split seamlessly across the `±180°` antimeridian, with a `+30m` forward propagation buffer in the API payload for smooth `30fps` client-side interpolation between refreshes, and no future ground-track line rendered), heading-locked dual instantaneous sensor scan swaths in `extremum` palette styling (wide swath `#f49a74` dashed `4,6` at `0.035` fill / `0.12` stroke below nadir swath `#92b4de` at `0.14` fill / `0.32` stroke; `400 km` nadir and `2,330 km` MODIS / `3,040 km` VIIRS wide swaths), rotated spacecraft SVG badges alongside nadir position markers, and a "Satellite passes" viewport overpass freshness card (latest pass per satellite, `ready` / `processing`, `~Xh delay`, `Next: <Sat> in ~Xm`) that refreshes on debounced map center moves (`≥ 25 km`) and every minute while visible with live elapsed-minute progression independent of `prefers-reduced-motion`, animated smoothly at `30fps` along the fetched CelesTrak orbital window. Picking a satellite flies to where it is at that moment.
- **Social Link Preview & Canonical Metadata**: Configures Open Graph (`og:*`) and X/Twitter (`summary_large_image`) tags in `ui/index.html` backed by a `1200×630` hero preview thumbnail (`ui/public/og-preview.png`) with build-time `VITE_SITE_URL` resolution in `ui/vite.config.ts` so deployed GitHub Pages unfurls use absolute HTTPS URLs without NASA branding.

### 2. Backend (`backend/` — ASP.NET Core `.NET 10` Container on Google Cloud Run)

- **CelesTrak TLE Caching, Swath Geometry & Overpass Freshness (`Satellites/`)**: Downloads TLE catalogs from CelesTrak (`GROUP=resource` for MODIS Terra/Aqua; `GROUP=weather` for VIIRS NOAA-20/NOAA-21), caches them for 12 hours in memory with embedded fallback TLEs, propagates J2 secular LEO trajectories, builds `49`-vertex (`12`-segment edge) high-latitude/polar-clamped nadir and wide swath polygons (`SatelliteSwathBuilder`), and evaluates 10-day lookback / 24-hour lookahead viewport overpass freshness (`SatelliteOverpassEvaluator`).
- **FIRMS Ingestion & Caching Proxy (`Firms/`)**: Directly queries the official NASA FIRMS REST Area API (`api/area/csv/{MAP_KEY}/{source}/{world|bbox}/{days}`) across `MODIS_NRT`, `VIIRS_NOAA20_NRT`, and `VIIRS_NOAA21_NRT`, normalizing satellite labels (`Terra`, `Aqua`, `Suomi NPP`, `NOAA-20`, `NOAA-21`) and MODIS/VIIRS confidence values (`0–100`; `low`/`nominal`/`high` mapped to `25`/`65`/`95`), caching area snapshots in `IMemoryCache` for 20 minutes, slicing to a rolling 24h window ("as of now", avoiding UTC calendar-day gaps) with `WindowStartUtc`/`WindowEndUtc` bounds and a 2-minute stale fallback if upstream refreshes fail, response compression, and server-side `FIRMS_MAP_KEY` isolation.
- **Spatiotemporal Harmonization Pipeline**:
  1. **Spatial Gridding**: Maps point detections onto a uniform grid (cell size ≥ 1 km, e.g. fixed equal-area / H3 / degree grid) while accounting for MODIS/VIIRS `scan` × `track` footprint growth toward scan edges.
  2. **Temporal Binning & Deduplication**: Aggregates detections per grid cell within daily/pentad windows to eliminate artificial inflation from multiple same-day satellite overpasses (Terra, Aqua, Suomi NPP, NOAA-20, NOAA-21).
  3. **Cross-Sensor Calibration**: Uses the post-2012 MODIS–VIIRS overlap period to align active-fire cell density and Fire Radiative Power (`FRP`) quantiles into a continuous multi-decade metric.
- **Satellite Cloud Proxy (`Clouds/`)**: Proxies `https://layers.extremum.org/v3/weather/satellite/{z}/{x}/{y}.png` (`z` `1..7`) with explicit `Referer`, `User-Agent`, and per-instance `gis-uuid` cookie plus `IMemoryCache` and in-flight request deduplication so client globes avoid upstream rate limits.
- **REST API Endpoints**:
  - `GET /health` — Cloud Run readiness/liveness probe.
  - `GET /api/status` — Service metadata and environment diagnostics.
  - `GET /api/fires/spots` — Compact rolling 24h (configurable `hours=1..48`, `sensor=harmonized|modis|viirs`, `bbox=w,s,e,n` or `world`) active-fire spots feed queried directly from NASA FIRMS Area API (`api/area/csv`) and cached for 20 minutes (`MODIS_NRT`, `VIIRS_NOAA20_NRT`, `VIIRS_NOAA21_NRT`).
  - `GET /api/fires/spots.geojson` — GeoJSON FeatureCollection projection of the cached rolling active-fire Area API snapshot.
  - `GET /api/satellites/orbits` — Time-bound orbital ground tracks, nadir position, heading, speed, swath parameters, TLE lines (`tleLine1`/`tleLine2` for client-side 24h negative-pass evaluation), computed `swaths` (`nadir`/`wide`), and `satelliteHud` overpass freshness entries (optional `lat`/`lng` query parameters) for Terra, Aqua, NOAA-20, and NOAA-21.
  - `GET /api/weather/satellite/{z}/{x}/{y}.png` — Cached `258×258` live `VIS/IR` satellite cloud tile proxy backed by `layers.extremum.org`.
  - `GET /api/anomalies/summary` *(planned)* — Regional & AOI current situation summary compared against historical calendar baselines (`fitsTypical`, `anomalyScore`, `zScore`, percentile).
  - `GET /api/seasonal/profile` *(planned)* — Harmonized multi-decade monthly/pentad climatology vs. current-year trajectory for the bottom seasonal scrubber and side inspector.
  - `GET /api/hotspots` *(planned)* — Spatial GeoJSON/vector hotspot clusters and harmonized grid cells for MapLibre rendering within a selected date window and sensor filter.
