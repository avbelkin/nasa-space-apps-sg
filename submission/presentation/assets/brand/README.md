# Presentation brand references

The slide builder uses only files inside `submission/presentation`.

These local references come from the official Space Apps brand collection: https://www.spaceappschallenge.org/brand/. The full guide is `brand-guide.pdf` (local, Git-ignored), downloaded from https://assets.spaceappschallenge.org/media/documents/Space_Apps_Brand_Guide_VUGpVJm.pdf.

- `palette.json` and `palette.css`: source palette and typography.
- `patterns/` and `reference/`: original reference images, kept locally.
- `../fonts/`: font files, licences and source hashes.

Presentation colours: Deep Blue #07173F, Electric Blue #0042A6, Blue Yonder #2E96F5, Neon Yellow #EAFE07 and White. Body text uses a blue or white background. Yellow is an occasional foreground accent. Fira Sans and Overpass are the approved type families. No NASA or Space Apps logos are used in this presentation.

The current redesign favours a solid background and larger typography. The guide's optional gradient and patterns are references, not mandatory elements on every slide.
